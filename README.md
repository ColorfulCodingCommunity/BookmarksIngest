## About

🪮 Pick what folders to scrap \
🤖 Scrap metadata from bookmarks automatically, in batches of 5 \
🛞 Generate a unified, AI-readable text file from all your bookmarks \
✅ Use that with any AI / LLM to query the data (ChatGPT, Gemini, Claude) - "What tutorials I have in my bookmarks about Chrome Extensions?"

## How to run on Google Chrome

- Clone the Repo (Or download ZIP)
- Access `chrome://extensions` in URL Toolbar
- Press `Load Unpacked` button. Pick the folder
- Done. Use as any other extension 👻
